# User Guide

Status: scaffold only (2 October 2026).

## Access

Run `corepack pnpm install` and `corepack pnpm dev` from the repository root, then open <http://localhost:3000>. The home page describes the planned Applicant and HR workflows for one company.

There is currently no sign-in, job listing, application form, HR review page, or AI feature to test. No public app deployment or test accounts are available yet. This guide must be updated as each feature is released so peer testers see only accurate instructions.

## Planned roles

- **Applicant:** view the company's published opening, write and submit a text-only application, and optionally request a SoCLaaS cover-letter draft for editing.
- **HR:** review applications to that company, write private notes, change application status, and optionally request a SoCLaaS summary of a cover letter against job requirements.

Both AI features are advisory. Applicants submit their own final text; HR makes every hiring decision.
