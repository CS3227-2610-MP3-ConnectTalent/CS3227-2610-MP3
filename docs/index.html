CS3227 Mini Project 3

Company Careers

A planned careers site for one company, showing only its own job openings and applications, with separate Applicant and HR roles.

Current status

The repository contains a working project scaffold and placeholder home page. Sign-in, applications, AI features, and the deployed app are still in development. This page will be updated to match the released product.

Applicant · planned

Browse this company's published roles by category, write a text-only application, and use a SoCLaaS draft as editable assistance before submitting.

HR · planned

Publish this company's job listings, review submitted letters, request requirement-based summaries, and make all status decisions personally.

The source repository contains the current user guide and developer guide under docs/.
