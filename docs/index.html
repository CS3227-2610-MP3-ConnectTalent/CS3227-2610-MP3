ConnectTalent

A careers portal for one employer per deployment, with separate Applicant and HR workflows.

Open the application

Current status

The implemented product includes verified accounts, Applicant profiles and applications, private PDF résumés, HR job management and review, and optional SoCLaaS assistance.

Documentation was checked against source and specifications on 12 October 2026. Authenticated hosted workflows remain unverified in this documentation review; the team must smoke-test the deployment before evaluator use.

Applicant

Complete a profile with name, verified email and phone, browse published roles by category, save application drafts and optionally attach a private PDF résumé. Use AI drafting assistance before submission, view application status and withdraw from an application's detail page. Submitted application details cannot be edited.

HR

Create and edit draft jobs, explicitly publish or close them, and review submitted applications and their attachments. Add private notes and request advisory AI summaries. HR makes status decisions through a separate human-controlled action; unsubmitted drafts remain private.
