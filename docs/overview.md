# ConnectTalent

A careers portal for one employer, with clear Applicant and HR workflows.

[Open the careers application](https://cs3227-mp3.vercel.app/)

## User Guide

[Read the User Guide](UserGuide.md) for account setup, required profile details, finding roles, applications and private PDF résumés. Applicants can save drafts, request an AI cover-letter draft and submit or withdraw an application. HR can manage jobs, review submitted applications, add private notes and choose application statuses. AI suggestions remain advisory.
