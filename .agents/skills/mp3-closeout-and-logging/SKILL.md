# Closeout and session logging

## Trigger and inputs

Use after review, or to prepare missing closeout artifacts. Read the [process](../../../workflow/AgentProcess.md), packet/record, final diff and checks, review/findings, actual student decisions and available session evidence. Follow the [archive rules](../../../workflow/archive/README.md) and [logging policy](../../../logs/README.md).

## Bounded actions

1. Reconcile task outcomes, requirement evidence, actual agent handoffs, review independence, findings/fixes/rechecks and missing checks in the [record](../../../workflow/templates/FeatureRecordTemplate.md). Record student acceptance/rejection/conditions only from an actual decision with source/date; do not infer it from passed checks.
2. After acceptance, sync accepted product deltas to canonical specs under the [ID/version policy](../../../workflow/specs/README.md). Compare final clauses/IDs against accepted deltas and implementation; record files, commit, version/date and evidence. Documentation/process work explains no product delta and sync N/A.
3. Archive the entire packet only after accepted sync and verification, preserving decisions, failures, handoffs and limits. Rejected/withdrawn packets follow their actual disposition without syncing unaccepted behavior. Record destination and repair/check current navigation; preserve historical log wording.
4. Update applicable guides/reflections within authorized authorship boundaries. Use the [summary template](../../../logs/SessionSummaryTemplate.md) for each substantive session: chronological prompts/follow-ups, real assignments/returns, material actions/results, decisions, files, checks, limits and student verification status. State unavailable coverage; never fabricate history or disclose secrets, private applicant data, sensitive full prompts or hidden reasoning.
5. Link every contributing session summary from the record, complete summaries before PR opening, and prepare final archived packet/record/log references. Inspect closeout changes and save the coherent final closeout commit when authorized; hand off to PR readiness.

## Output and handoff

Return final record/packet/archive/log paths, actual acceptance source, sync/closeout commits, checks, findings and pending gates. PR-ready is a supported state only when the pre-PR gates have evidence; this skill does not open a PR or authorize merge/release.

## Quality and evidence checks

Check complete-packet preservation, accepted-delta equivalence, IDs/version/navigation and all session links. Separate self-review from independence and actual student verification from pending status. Log only available interactions; preserve existing summaries unless a demonstrated factual correction is documented.

## Stop conditions

Stop accepted spec sync/archive for missing acceptance, blocking findings without an explicit student disposition, or conflicting deltas. Continue authorized evidence/log drafts with gates pending. Report access/authorship blockers and decision owners; never relabel missing decisions as complete.
